# ADR-0001 — Fundação do Projeto

## Status

Aceito

## Contexto

O ColabDevKit será desenvolvido como uma biblioteca Python moderna,
voltada para apoiar o desenvolvimento de projetos utilizando o Google Colab.

Desde o início, decidiu-se adotar uma estrutura profissional,
compatível com as recomendações atuais da comunidade Python.

## Decisão

O projeto utilizará:

- pyproject.toml como configuração principal;
- estrutura em pacote Python;
- documentação versionada;
- registros de decisões arquiteturais (ADR);
- desenvolvimento incremental por Sprints.

## Consequências

O projeto terá maior organização,
facilidade de manutenção
e poderá evoluir de forma sustentável.
